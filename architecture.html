DeepResearch Agent Architecture

Autonomous multi-step research agent powered by SerpApi + LLM reasoning (LangGraph)

SerpApi Integration

  • • 5 engines: Search, Scholar, News, Patents, Trends
  • • 10-25 meaningful API calls per research question
  • • AI Overview + Knowledge Graph extraction
  • • Citation count parsing from Scholar
  • • Deduplicated & pre-filtered before evaluation

Agent Pipeline (LangGraph)

  • • Plan → Search → Evaluate → Synthesize loop
  • • Up to 3 iterations with adaptive re-planning
  • • Hybrid scoring: heuristic + LLM gap analysis
  • • Stops early when quality ≥ 85%
  • • Supports OpenAI and Anthropic LLMs

Output Quality

  • • Cited research report with inline references
  • • Per-source relevance scoring & credibility rating
  • • Contradiction detection between sources
  • • Coverage gap identification
  • • Confidence assessment (High / Medium / Low)
